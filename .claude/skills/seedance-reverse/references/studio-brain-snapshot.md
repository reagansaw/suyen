# studio 大脑快照（离线用）

> 这是 studio.aigoal.ai 大脑（提示词指南 2026-09-28 版 + 词典 + gem 手艺卡）里反推最用得到的部分，2026-11-19 截取。
> **有 studio 钥匙时，开工先跑 `scripts/fetch_brain.py` 拿最新版**，最新版和这份不一样时以最新版为准（skill 的实测规则除外，见 SKILL.md「大脑和 skill 谁说了算」）。没有钥匙的学员就用这份。

## 一、规格

| | Seedance 2.0 Custom | Seedance 2.5 | Seedance 2 Mini |
|---|---|---|---|
| 一段长度 | 4–15 秒 | 4–30 秒，任意整数秒 | 照 studio 说明 |
| 参考图 | 最多 9 张 | 最多 30 张 | 最多 7 张 |
| 参考视频 | 照 studio 说明 | 最多 10 段，合计 ≤30 秒 | |

- 档位决定分辨率：快速 = 720p · 标准 = 480p / 720p · 高清 = 1080p / 4K。先用快速档出小样。
- 比例：16:9 · 9:16 · 4:3 · 3:4 · 1:1 · 21:9。
- 点数看 studio 的 `get_schema`（credit_examples），按档位、分辨率、秒数算。
- studio 上传只收 JPG / PNG、MP4、MP3；HEIC、MOV、M4A、WAV 要先转。图 ≤30MB、影片 ≤100MB、声音 ≤30MB。

## 二、马来西亚讲价钱

马来西亚华语讲价钱（不是课本讲法）：一万以下正常念加「块」——八十八块、四千五百块；一万到一百万用「千」当单位、不加块——十二千、四十五千、四百五十千；一百万以上用「万」、不加块——一百二十万、两百五十万。不要讲「令吉」，450,000 也不要讲成「四十五万」。台词过 normalize_dialogue 会自动转好。

## 四、中文安全运镜词

中文提示词用中文运镜词，裸写 Dolly / Crane / Aerial 可能被审核当成人名或品牌。

|---|---|
| Dolly in / out | 推轨推进 / 推轨后拉 |
| Crane / Jib | 摇臂升降 |
| Orbit / Arc | 弧形环绕 |

| Leading shot | 镜头在主体前方缓慢后退引导 |
| Following shot | 背影稳定跟随 |

## 五、运动强度梯子（治「糊动」）

每个动作都要带强度和方向，不然 Seedance 出来的是一团糊动。强度要配运镜速度，也不要自相矛盾（「轻柔地猛冲」）。

| 强度 | 用词 | 用在 |
|---|---|---|
| 极强 | 爆发、猛地砸下、炸开 | 打斗、爆炸 |
| 强烈 | 剧烈、迅猛、用力 | 追逐、情绪高潮 |
| 突然 | 猛然、一下子、骤然 | 惊吓、转折 |
| 中等 | 平稳、自然、利落 | 日常叙事 |
| 轻柔 | 轻轻、缓缓、柔和 | 浪漫、ASMR |
| 渐进 | 慢慢、一点一点、不知不觉 | 日出、情绪渐变 |

## 六、画风轨道：一条片只走一条

- **UGC 手机真实**（studio 默认，带货、口播、短剧都用这条）：有方向的自然光（窗边、街上、白天）、真实的软阴影、偶尔镜头脏污或逆光眩光、自动曝光在调整的感觉；**绝不加电影调色**，必须像真手机拍的。
- **电影感 / 大片**：可以写胶片型号（Kodak Portra 400 对付蜡像脸）、焦段 mm 数、光学瑕疵（胶片红晕、宽银幕眩光）、大气（薄雾、光束）。
- 反推时先判定原片走哪一条，写进结构拆解；换内容也照同一条走。要换轨道先问用户，并且全片一起换。

## 七、品质冲突矩阵（别混搭）

| 冲突 | 怎么办 |
|---|---|
| 手持晃动 × 绝对对称构图 | 对称构图就用三脚架 / 稳定器 |
| 慢动作 × 变速（speed ramp） | 同一时间段只能一个，分段用 |
| 电商产品 × 胶片颗粒 | 电商禁胶片；影片禁数码锐 |
| 三渲二卡通 × 写实材质（毛孔、透光） | 二选一 |
| IMAX 极致清晰 × VHS 复古降解 | 二选一 |

## 八、灯光分三层写

1. **光源**：什么光、从哪来（窗边进光、阴天漫射、黄昏侧逆光、霓虹、台灯侧光、屏幕冷光）。
2. **光行为**：光和东西怎么互动（光束穿过薄雾、雨水反射霓虹、皮肤透光）。
3. **色调**：整体色彩（低饱和灰 + 微暖高光、柔粉 + 金色微光、高饱和社媒鲜亮）。

一整套灯光配方比单个光源词强很多。

## 九、焦段和景深

模型对 mm 数很敏感，写「14mm 超广角」远强过「广角镜头」。原片明显靠焦段做效果时，反推就写 mm：

| 焦段 | 效果 |
|---|---|
| 14mm | 夸张变形、压迫、巨物感 |
| 24–35mm | 自然空间、街头纪实、交代环境 |
| 50mm | 最像人眼、平实对话 |
| 85mm | 柔美虚化、人像、产品美拍 |
| 135–200mm | 极致压缩、奶油虚化、微表情、偷窥感 |

拉焦三种：缓慢拉焦（回忆、渐悟）、急速跳焦（惊吓、发现）、呼吸焦点（焦点微微游移，紧张不安）。

## 十、演员调度三要素（多人戏必写）

每个画面里每个人都写：**① 站位**（画面左边 / 门口）· **② 面部朝向**（侧脸对镜头 / 背对镜头）· **③ 视线焦点**（视线温柔地落在某某脸上）。拍摄角度写具体：「过肩近景，从 A 背后拍，焦点在 B 的脸上」。

## 十一、台词和声音

- 一段 15 秒最多 2–3 句短台词，大约 95 个中文字以内。
- 画外音 / 内心独白写「画外音：『…』」，并加「画面中的角色不要出现说话口型」。
- 音效写成看得见的物理声音：材质 + 力度 + 表面（「高跟鞋清脆地踩在大理石地上」），再加空间感（空旷回声、室内闷声）。
- 要方言就直接写「用粤语说」「用福建话说」。

## 十二、片型模板速记

- **一镜到底**：开头就宣告「一镜到底，全程不切镜头」。
- **多镜头混剪**：开头写「多镜头视频」。
- **Before / After**：同一个机位角度，中间用遮挡或闪白转场。
- **电商产品三段**：0–3 秒慢速环绕 → 3–7 秒微距特写材质 → 7–10 秒拉远揭示使用场景。
- **视频延长**：生成秒数填新增的秒数；也可以往前延长（前传）；上一段最后 2 秒要稳住，当交接帧。
- **防滑步**：写重心转移、惯性、和地面的互动（踩水、碎石溅起）。
