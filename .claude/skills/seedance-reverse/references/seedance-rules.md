# Seedance 2.0 提示词写法

AIGOAL 实测整理。写每一段提示词之前照这份对一遍。

## 能力与限制

- **一段 4–15 秒。** 超过 15 秒就拆成两段接力（或改用 Seedance 2.5，它一段可到 30 秒）。
- **会自己出声音**：台词、环境声、音效一起生成，嘴型对得上。
- **两种做法，一段只能选一种：**
  - **参考模式**：最多接 9 张图，提示词里用 `@image1`、`@image2` … 叫它们。要保人物、产品不走样时用。
  - **首帧模式**：一张图当第一格（可再加一张当最后一格），影片从这张图开始动。要锁死构图、锁死两个人的位置、做前后对比时用。
  - 在 studio.aigoal.ai 上，首帧和参考图不能同时接，同时接会被挡下来。即梦的「全能参考」入口里可以写「@图片1 作为首帧」再加别的参考；「首尾帧」入口不行。
- 叫法因平台而异：studio.aigoal.ai 用 `@image1`、`@video1`、`@audio1`；即梦用 `@图片1`、`@视频1`、`@音频1`（即梦不认英文叫法）。交付时照用户用的平台写；不知道就用 studio 的写法并提一句。
- **studio 各型号的规格**（2.0 / 2.5 / 2 Mini、档位、比例、上传格式）见 `studio-brain-snapshot.md`「规格」，有钥匙时以 `fetch_brain.py guide` 拿到的最新版为准。
- **即梦的素材上限**：图最多 9 张；视频最多 3 段、合计 2–15 秒、每段小于 50MB；音频最多 3 段、合计不超过 15 秒；全部加起来最多 12 个。studio 上 Seedance 2.0 Custom 最多接 9 张图，Seedance 2.5 更多（见 studio 的模型说明）。
- **提示词长度**：上限大约 2000 个字符，**目标控制在 1900 以内**，要真的数，不要估（实测估的常常少算一千多字）；搭画布的脚本会帮你数。经验值：每个镜头不超过 200 字，一段 15 秒不超过 800 字最稳，太长模型反而抓不住重点。
- **真人照片当参考**：即梦官方手册写明不支持写实真人脸部素材，会被拦截；studio 走 API，规则可能不同。用户本人出镜时，第一次一定先拿一段试；被拦的退路：①用图片模型把他做成一张高度相似的定妆照再当参考，②改用首帧模式，③只拍不露脸的部分（手、背影）。

## 公式

```
[总长 + 画幅 + 主体 + 核心动作] → [人物、场景的 @image 绑定] → [按秒分拍：画面 + 运镜] → 灯光：… → 质感：… → 声音：环境声 + 按时间写台词 → 不要：…
```

每一段都照这个顺序写，学员拿到手一眼就知道哪一块管什么。完整示范见 `examples/`。

**开头 20–30 个字最值钱。** 模型靠开头锁主体，所以第一句就写：几秒 + 画幅 + 最有辨识度的主体 + 核心动作。

## 按秒分拍

```
0–3s：……
3–8s：……
8–12s：……
```

一拍一个清楚的动作。原片在这一段里有几个镜头，就分几拍，并写明「切到」。

- **生成秒数留余量**：AI 片段开头和结尾各约 0.5 秒最不稳（起手抖、收尾乱动），剪辑时要剪掉。所以一段生成的秒数 = 原片那几镜的长度 + 0.5–1 秒，取整数，最多 15 秒；第一拍从 0.5 秒左右才开始做事。
- **表情写成看得见的动作**：写「嘴角慢慢上扬、眼睛眯起来」，不写「很开心」。
- **动作拆成 3–5 步的顺序**：「伸手 → 拿起手机 → 翻过来 → 举到镜头前停住」，并写清楚左手还是右手。动作幅度越大越容易崩，能小就小。
- **反应要给时间**：吓一跳至少 1.2 秒、脸红至少 2.5 秒、哭至少 3 秒，太短模型做不出来。
- **一闪而过的东西**要写明秒数和「随即恢复」，例如「0.5 秒的闪白，随即恢复原画面」，不然它会做成两三秒。
- **人不要像雕像**：对话、凝视的画面写一句持续的小动作（呼吸起伏、眨眼、发丝微动、视线移动）；不想要的大动作才在「不要」里点名。
- **段落之间的衔接点**：每段最后一拍写清楚结尾停在什么画面、人物什么状态，下一段开头就从这个状态接。

（这一节的余量、反应时长、闪现和小动作几条，整理自 MapleShaw/seedance2.0-prompt-skill 的实测，MIT 授权。）

## 用原片当运镜参考（@video1）

最直接复刻运镜和节奏的方法：把原片那一小段剪出来当参考视频，提示词写：

```
运镜和节奏完全参考 @video1，不要复刻 @video1 里的人物、场景和文字。
```

- 剪法：一段 3–8 秒，里面只有一种运动（例如只有那个一镜到底的拉开），剪掉开头 1–2 秒的起手抖动。
- 适合：原片的运镜很难用文字描述清楚（复杂的一镜到底、环绕加升降、快速跟拍）。
- 风险：原片里有真人脸可能被拦；接了参考视频的生成通常比较贵；studio 上要接 `ref-video-1`，第一次先单段试。文字写得清楚的运镜，不用这招。
- 分镜板、多宫格图（包括我们的镜头条）拿来当参考时，一定要写「只参考构图和节奏，不要画出格子边框、编号和分隔线」。

## 段和段怎么接

1. **截上一段最后一格当下一段首帧**（首帧模式）：最稳，构图和人都接得上。
2. **视频延长**：把上一段当 @video1，写「将 @video1 延长 X 秒」，生成秒数填**新增**的秒数；开头写「接续上一段最后一格的构图和人物状态」，前 0.8–1.5 秒只做很小的动作，再开始新的事。
3. **独立生成再剪接**：场景本来就换了的段落用这个，靠剪辑和转场接。

## 音乐卡点

原片是卡点型（画面跟着节拍切）才需要：接一段音乐当 @audio1（或原片当 @video1），写「画面跟着 @audio1 的节拍切换，重拍时 … 」，并在分拍里写死哪一拍落在哪个动作上。一般剧情片的配乐还是放后制。

## @image 绑定：每一张都讲清楚拿来干嘛

| 用途 | 写法 |
|---|---|
| 人物 | `@image1 为人物参考，全片保持同一张脸、同一套衣服、同一个人` |
| 产品 | `@image2 为产品参考，外形、颜色、logo 位置保持一致` |
| 场景 | `场景参考 @image3` |
| 服装 | `穿 @image4 的衣服` |

- 只写「参考 @image1」不够，要写参考它的**什么**（脸？衣服？产品？构图？）。
- **编号每一段从 @image1 重新排**，只接那段用得到的图。全片用「图A、图B…」当图的名字，每段开头写「接图：@image1 = 图A，@image2 = 图C」。
- 提示词里提到的每个 `@imageN` 都要真的接了图，编号从 1 连着排。
- 只在一段里露面的配角不用参考图，写外形就好。主角、反复出现的场景才值得出一张图。
- 人物换衣服（小时候 / 长大、便服 / 制服）：绑定写「保持同一张脸」，不要写「同一套衣服」，衣服在那段另外写。

## 运镜：一拍只给一个主运镜

定镜 · 缓慢推近 · 缓慢拉远 · 横摇 · 直摇 · 跟拍 · 环绕 · 手持

- 用 缓慢 / 平稳 / 轻微 这种节奏词，别写技术参数。
- 运镜和人的动作**分开写**，不要搅在同一句。
- 同一拍别又「定镜」又「环绕」。

## 灯光：每一段都写

对画质影响最大的就是灯光。每段在分拍后面写一行「灯光：…」：光从哪来、冷还是暖、硬还是软（窗边自然光、黄昏逆光、柔和轮廓光、室内暖色顶灯、阴天漫射光 …）。段里某一拍换了光（开灯、走出室外），才在那一拍另外写。

## 质感

- 要真实，每段的「质感」都写：`真实实拍质感，皮肤看得到毛孔和自然的光影明暗，不要磨皮、不要美颜、不要塑料感或 CG 感`。
- 光写「真实皮肤纹理」不够，模型默认还是会给磨皮、美颜过的脸。一定要连「不要什么」一起写。
- 不要写「雀斑」「瑕疵」「不完美肌肤」，它会真的画一脸斑。
- 不要写 4K / 8K / masterpiece / best quality / ultra HD / 电影级，这些会让写实画面变塑料。（有些 skill 要求每段都加「4K超高清」，那是给 CG、奇幻大片用的；真人写实、UGC、口播一律不加。）
- 要更像手机实拍，可以写来源型的小缺陷：轻微的平台压缩感、暗处一点噪点、白平衡略偏、手机广角的轻微变形。
- 手机随手拍风格：手持、自然手机画质、轻微晃动、不调色。

## 素材图（定妆照、场景图）也要真实

Seedance 会照参考图的质感拍。定妆照像影棚模特照，出来的影片就像广告；所以素材图的提示词要先写对。实测踩过的坑：写「正面半身照，浅灰纯色背景」，出来是磨皮、摆姿势的影棚模特照，场景图是干净得像渲染图的室内设计效果图。

- **人物**：写成「一张像朋友 / 家长用手机随手拍的真实照片」，人站在真实的地方（走廊、店屋、住家门口），用自然光，不要纯色背景。
- 加上真实感那句：`真实皮肤纹理，看得到细小毛孔和自然的光影明暗，肤色不均匀的地方照实留着；没有美颜、没有磨皮、不是影棚照、不是广告模特`。
- 给一两个生活痕迹：几根乱翘的头发、晒过太阳的肤色、一点胡渣、表情放松没在摆姿势。不要写雀斑、瑕疵（理由同上）。
- 人物身上没有的东西（眼镜、帽子、胡子）就整个不提，不要写「没有戴眼镜」。提到了，模型反而常会画出来。「不要」那一行只用来防模型常犯的错（多手指、字幕），不用来描述外形。
- **多人戏写演员调度**：每个人的站位、面部朝向、视线落在哪里（见快照「演员调度三要素」），不然视线和朝向会乱。
- 当地人要写清楚：`马来西亚华人`，也可以加「不是韩系偶像造型」，不然模型常给偶像脸。
- **场景**：写成「一张像手机实拍的真实照片」，加磨损、污渍、用过的东西、日常的灯光，再加「不要太干净，不要像渲染图 / 设计效果图」。

## logo 要怎么进画面

Seedance 自己画 logo 会变形，但 logo 可以先交给图片模型放进素材图，Seedance 只是照着拍：

- logo 上传当一张图（素材清单里叫「图L」）。
- **场景里的 logo**（招牌、布条、海报）：生成场景图时把图L 当输入（图生图），提示写「印着 @image1 的 logo，形状、颜色、字母照 @image1 一模一样」。这张场景图再当 Seedance 的场景参考。
- **要特写的 logo**（手机屏幕、包装）：用图生图做一张特写，输入人物图和图L，单独生成一段 4 秒的首帧模式插入镜头，剪进去。
- 出片后 logo 若还是变形，那几秒后制盖一张原图。后制贴 logo 一直都是保底做法。

### 1. 念错字

- 字母缩写用连字号一个一个念：`L-R-T`、`K-L-C-C`。
- 数字写成嘴巴讲的样子：「八十八块」「四百五十千」「一百二十万」。
- 品牌名、公司名、人名靠写法救不了，同一种写法会一次对一次错。一定要念对的，就另外生成配音，或把这句留到后制配音，并在交付里提醒用户出片后先听这几句。
- 同一句台词全片只讲一次，写明「台词都只讲一次」。首尾呼应的金句也只生成一次，后制复用那一段。
- 台词放在分拍后面的「声音」那一块，按时间写：`0–7.5s 某某用（语气）的语气说：「…」`。每个说话的人都写语气。
- 没有画面主人的旁白不要叫 Seedance 生成，放后制配音。
- 同一个人跨段的声音会有点不一样。要连贯，每段都写一样的声音描述（年纪、口音、语气）；更讲究就后制统一配音。

## 用真人的声音（@audio1）

用户本人或代言人出镜时，接一段他的真声当声音参考，Seedance 会用这把声音讲新台词。

- **素材**：一段 10–15 秒的干净口播，没有配乐、没有别人的声音，开头结尾不要切在字中间。素材清单里叫「声A」，档案写 mp3。
- 每段开头在「接图」下面加一行：`接声音：@audio1 = 声A`。编号跟图一样，每段从 @audio1 排。
- 声音那一块第一句先绑定，**用衣着认人**：`@audio1 是女命理师（@image1，穿玫红色西装、戴眼镜的那位）的声音参考，她的每一句都用 @audio1 的声音讲；@audio1 只用来定音色，不要把这段录音当成背景声播出来。`
- **每一句她的台词都标上**：`女命理师（穿玫红色西装）用 @audio1 的声音说：「…」`。不标的话，模型会把整段录音当背景音轨播出来。
- **同段的其他人要写明不用这把声音**：`小男孩用他自己的童声，绝不用 @audio1 的声音。` 不写的话常会变成两个人用同一把声音。
- 两个人都要真声：@audio1、@audio2 各绑一个人，每句都标，衣着要差很多，模型靠「看见的人」认声音，不靠编号。

### 2. 画面里的字一定乱码

Seedance 写不出正确的字和数字，重生成也没用。

- 不叫它写任何字：店名、价钱、slogan、字幕、手机屏幕上的字都不要。
- 画面里只是顺带有招牌、手机、文件，就写「屏幕背对镜头 / 失焦 / 看不清文字」。
- 字幕、花字、价钱卡全部放后制。
- **要秀给观众看的屏幕（App、网站、logo）**：写「把手机屏幕正面朝向镜头举稳不动，屏幕是一片干净的白光」，不要写屏幕上有什么，「不要」里加「手机屏幕上出现任何图案或文字」。出片后把真的画面贴进那块白光，手机不动就只要贴一次。
- 要秀的是招牌、海报、包装上的字：那一镜用图片模型先出图，单独用首帧模式生成，或后制贴上去。

### 3. 不合物理

- 一拍只做一个简单动作。
- 难的接触动作（开门、握手、倒水、手拿小东西）用剪接跳过：不演「打开门」，直接切到「门已经开了」。
- 手尽量不碰产品，在旁边用手掌指着。
- 不写不限定的「快速」，写「缓慢」「平稳」。

### 4. 两个人会乱

- 两个人外形要差很多：衣服颜色、发型、年纪。
- 位置写死：`@image1 的女人在画面左边，穿红色；@image2 的男人在右边，穿蓝色`。
- 不要让两个人交叉、换位、擦身而过。
- 能分开拍就分开：一镜一个人（正反打）比两人同框稳。原片的过肩镜头，前景那个人只露后脑和肩膀，写成「前景是一个背对镜头的失焦人影」就够了。
- 最稳：先用图片模型把两个人合成一张图，拿它当首帧。

### 5. 段和段之间变脸，或自己加东西

- 同一个人、同一件道具，**每一段都一字不差地把外形再写一遍**（年纪、发型、衣服、颜色、配件）。
- **模型会照刻板印象自己加东西**：中年女命理师常被加上眼镜，老师加眼镜、老板加西装。提示词里不提也会加。防法：
  - 主角排在**第一张参考图**。排在后面、参考图又小（全身照里脸只占一点）的时候，模型最抓不牢。
  - **正面写出那个部位的样子**，例如「双眼直接露在外面，脸上只有口红」，不要写「没有戴眼镜」。
  - **用已经出片、确认像的那一格当第二张脸部参考**：第 1 段出片后，截一格脸清楚的特写，接给后面有她的每一段，写「@image1 定衣服和造型，@image2 定她的脸，脸照 @image2」。一段比一段稳。
- 要最连戏：上一段出片后，截它的最后一格当下一段的首帧。

## 结尾的「不要」

基本款：

```
不要：画面出现任何文字、字幕、logo、水印；人脸变形、多出手指、手部变形、物体穿过身体；
中途换人、换衣服、换场景。
```

再按这一段最容易出错的地方加一两条，不要每段贴一样的：两人正反打加「两个人的正脸同时出现在一个画面里」；有桌子、手枕加「手穿过桌子」；配角不露脸加「某某露出正脸」；秀屏幕加「手机屏幕上出现任何图案或文字」。
