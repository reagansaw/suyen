# 交付格式

存成 `<输出文件夹>/反推结果.md`。完整示范见 `examples/桃花不浅-反推结果.md`。

````markdown
# 反推结果：<给这条片起个名>

原片：<文件名或链接> · <总长>秒 · <画幅> · <N> 个镜头
平台：<studio.aigoal.ai（写 @image1） / 即梦（写 @图片1）>
本次替换：<人物 / 产品 / 场景 / 都不换>
故事：<只换皮 / 借结构重写（方案 X，另外两个方案见下）>

## 一、结构拆解

- **钩子**：
- **结构公式**：A → B → C → D
- **节奏**：平均 X 秒一镜；哪里快、哪里慢
- **产品怎么进来的**：
- **为什么会火**（一两句）：
- **难还原的地方**：哪些画面 Seedance 很难做（屏幕字、复杂手部动作、多人互动、特殊特效），打算怎么处理

## 二、镜头表

|---|---|---|---|---|---|
| 1 | 0.0–1.2 | 特写 · 定镜 | … | 「…」 | 钩子 |

### 运镜设计（导演逻辑）

只列关键时刻。

| 时刻 | 怎么拍 | 为什么这样拍 |
|---|---|---|
| 揭晓（31.7–35.7） | 手部极致特写停 1.5 秒 → 一镜到底往后拉、升起，依次露出手枕、甲油、整间店 | 先让观众以为是牵手（误导），再一口气揭晓是美甲（包袱） |

| 人物A | … | 1, 4, 6 | <用户的> |
| 产品1 | … | 6 | <用户的> |
| 场景甲 | … | 1–6 | <用户的> |

## 四、素材清单（生成前要准备好）

| 图 | 是什么 | 有了吗 | 用在 |
|---|---|---|---|
| 图A | 人物A 定妆照，正面半身 | ✅ `素材/人物A.jpg` / ⬜ | 第 1、3 段 |
| 声A | 人物A 的真声，10–15 秒（本人出镜才要） | ✅ `素材/人物A-声音.mp3` / ⬜ | 第 1、3 段 |
| 后制 | logo、产品截图 | ✅ `素材/logo.png` / ⬜ | 贴进第 X 段 |

没有的图，用图片模型照下面出（一行一张，搭 studio 画布的脚本会读这几行）：

- **图A**：「…（图片提示词）」
- **图D**（输入：图L）：「…印着 @image1 的 logo…」　← 要拿别的图当输入（图生图）时这样写，提示里照输入的顺序叫 @image1、@image2

人物、场景图的提示词照 seedance-rules「素材图也要真实」写，不要写纯色背景的影棚照。logo、产品照这类要放进画面的图，列成「图L」等一般的图（不要放在「后制」那行），才能当输入。

每段只接那一段用得到的图，编号在每段里从 @image1 重新排（见每段的「接图」）。

「有了吗」那格的档案路径要用反引号括起来，相对于这份 .md 所在的文件夹。

## 五、分段提示词

### 第 1 段 · 对应原片 0–13.5 秒 · 生成 14 秒 · 参考模式

接图：@image1 = 图A（人物A），@image2 = 图C（场景甲）
接声音：@audio1 = 声A（人物A 的声音）　← 没有真声就不写这一行

```

@image1 为…的人物参考，全片保持同一张脸、同一套衣服：（外形，每段一字不差）
场景参考 @image2：（场景一句）

0–3s：（画面 + 运镜）
3–8s：切到……

灯光：……
质感：……

声音：（环境声）。台词都只讲一次。
0–3s 某某用（语气）的语气说：「……」

不要：（基本款 + 这段最容易错的一两条）
```

衔接点：这一段结尾停在什么画面、人物什么状态（下一段从这里接）。

标题里的「生成 N 秒」和「参考模式 / 首帧模式」，搭 studio 画布的脚本会读，格式不要改。

- **花字 / 贴纸**：
````

## 写法要点

- 提示词放代码块，一段一个，用户能整段复制。
- 每段标题写清：对应原片哪几秒、生成几秒（整数）、用参考模式还是首帧模式、接哪几张图。
- 原片里同一个镜头出现两次（回忆、回扣），不要生成两次，在后制清单里写「复用第 X 段的 X–X 秒」。
- 待用户补的内容统一写成 `【填：…】`，交付时把所有待填项在最后列一遍。
