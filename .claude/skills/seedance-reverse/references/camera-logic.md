# 导演级运镜逻辑

运镜不是装饰。每一个镜头怎么动、动多快、停在哪里，都在回答一个问题：**这一刻要观众感觉到什么、知道什么、什么时候才知道。**

反推时，先看懂原片每个关键时刻的运镜「为什么这样拍」，再写进提示词。只抄「镜头往后拉」，不知道它是为了误导再揭晓，写出来的节奏就会错：拉太早、拉太快，或者被切成三个镜头，包袱就没了。

## 先拉慢帧，才看得出运镜

一秒几格的镜头条看得出景别，看不出运镜。关键时刻一定要慢拉片：

```bash
python3 "<skill>/scripts/analyze_video.py" "<视频>" --out "<输出文件夹>" --slow 31.5 36
```

每秒 8 格，逐格看。要慢拉的地方：

- **钩子**（前 3 秒）
- **揭晓 / 反转 / 包袱**那一刻
- **转场**（甩镜、闪白、前后两个场景）
- 脚本切出**同一个主体连着两三条短镜头**的地方：很可能根本不是剪接，是一个快速、连续的运镜被误切了

判断是切还是一镜到底：相邻两格画面里有没有同一样东西、位置只是平移或变大变小。有，就是同一个镜头在动；整个画面换掉，才是切。

## 常用的运镜逻辑

| 逻辑 | 怎么拍 | 观众感受 | 写进提示词 |
|---|---|---|---|
| **误导 → 揭晓** | 先用很紧的画面藏住环境，停一拍让观众误会，再一镜到底往后拉 / 升起，按顺序露出线索，最后停在交代一切的全景 | 「原来是这样！」 | 写清楚：开场画面只看得到什么、停几秒、镜头怎么移动、**依次**露出哪几样东西、停在什么画面。**整段写成同一个镜头，不要写「切到」**，每一拍都写「镜头继续…」。文字写不准就剪原片这一段当 @video1（见 seedance-rules「用原片当运镜参考」） |
| **缓慢推近 = 领悟 / 情绪加重** | 人物听到关键一句、想通、愣住时，镜头极慢地推近他的脸 | 跟着他一起「懂了」 | 「镜头极缓慢地推近他的脸」放在他愣住那一拍 |
| **低机位仰拍 = 权威** | 拍「给答案的人」时机位稍低 | 她说的话有分量 | 「稍低的机位微微仰拍」 |
| **小孩视角** | 机位放在小孩眼睛的高度，大人在画面上方 | 代入小孩 | 「机位放在桌面高度」 |
| **定镜 vs 手持 = 冷静 vs 激动** | 冷静的人用定镜，激动的人用轻微手持晃动，正反打来回切 | 两个人的状态一眼对比 | 每一拍分开写：「这一拍轻微手持晃动」「这一拍定镜不动」 |
| **纵深里的孤独** | 主角在画面深处的远方，人群从前景走过、把他挡住又露出 | 他被排在外面 | 「他站在走廊深处，画面中间是大片空着的走廊，同学从前景经过」 |
| **出画留白 = 被拒绝 / 失去** | 对方走出画面，镜头不跟，留下主角一个人在画面一侧，另一侧空着停一拍 | 空落落 | 「她走出画面右边，镜头不动，画面右边空着，停一秒」 |
| **后退跟拍** | 镜头在人物前方，跟着他的速度往后退 | 跟着他的情绪走 | 「镜头在他前面缓慢后退跟拍」 |
| **过肩 = 对峙** | 前景是一个人的肩膀或后脑，焦点在对面的人 | 两人之间的关系、压迫感 | 「前景是某某失焦的肩膀」 |
| **回扣 = 同一个画面再出现** | 结尾重复开头那个镜头的构图和台词 | 首尾呼应，包袱落地 | 不要重新生成，后制复用那一段 |
| **声音桥** | 上一场的台词尾巴盖到下一场的画面上 | 把预言和兑现连起来 | 写进后制清单：「某句台词延续到下一段开头」 |

## 写进提示词的要点

- **一拍只有一个主运镜**，但一个主运镜可以很长、可以复合（往后拉的同时慢慢升起）。误导 → 揭晓就是一拍，写清楚时间。
- **揭晓前一定要停。** 紧画面先停 1–1.5 秒让观众误会，再开始动。没有停，误导就不成立。
- 运镜写**依次露出的东西**，模型才知道镜头往哪走、走多远：「先露出粉色手枕，再露出桌上的甲油，最后看到整间美甲店」。
- 写速度和终点：「缓慢、平稳地往后拉，停在全景」。不写终点，模型会一直动。
- 运镜和人物动作分开写成两句。
- **贯穿整段的运镜，每一拍都再提一次**（「镜头继续缓慢往后拉」），不然模型会把每一拍当成新镜头，运镜就断了。
- **近景加大幅环绕会崩脸。** 一个镜头最多同时动两样（距离、高度、绕的角度三选二）；近景只做小幅度的移动。
- **景深和焦段要写出来**：浅景深、背景虚化、拉焦（缓慢拉焦 = 渐悟，急速跳焦 = 惊吓）。原片明显靠焦段做效果时（85mm 人像虚化、135mm 压缩、14mm 广角变形）就写 mm 数，模型对 mm 很敏感，比写「长焦」「广角」准（studio 大脑实测，见快照「焦段和景深」）。不要写轨道长度、速度数字这类参数。

## 交付时

在镜头表后面加一张「运镜设计」，只列关键时刻（钩子、转折、揭晓、回扣），三栏：时刻、怎么拍、为什么这样拍。学员看这一张就懂导演在想什么。
