# 替换手册：把原片换成用户自己的

用户要的通常是「结构和节奏照旧，人、产品、场景换成我的」。先分清哪些是骨架、哪些是血肉。

## 骨架（保留）和血肉（可换）

| 保留 | 可换 |
|---|---|
| 钩子的类型（一句反常的话、一个悬念） | 钩子的具体内容 |
| 结构公式和每一步的先后 | 人物是谁、长什么样 |
| 每一镜的时长和快慢 | 产品 |
| 景别、机位、运镜 | 场景、道具、服装 |
| 情绪曲线（期待 → 失落 → 反转） | 台词的具体用词 |
| 产品进场的方式和时间点 | 画面字、字幕、配乐 |

## 先做一个测试：包袱还成立吗

很多爆款的包袱是长在原来的产品、职业或场景上的。换之前问自己：**把原片的那样东西拿掉，结尾还好笑 / 还说得通吗？**

- **成立**（产品只是背景或道具）：直接换皮，剧情不用动。
- **不成立**（包袱靠的就是原来那样东西）：必须借结构重写，为用户的产品重新找一个「意外但合理」的兑现方式。

例子：原片是算命先生对小男孩说「你以后每天牵不同女人的手」，长大后他成了美甲师。包袱靠的是「美甲师每天牵女人的手」这个双关。用户如果卖的是保险，硬把美甲店换成保险公司，包袱就没了。要重新找一句预言和一个职业，让预言字面听起来是一回事、兑现时是另一回事，例如「你以后天天有人追着你要签名」→ 长大成了送快递的。

重写时列两到三个方案（各一两句），挑你最推荐的那个写完整的镜头表和提示词，请用户选；他选了别的再改写。不要三个都写完整，也不要停下来什么都不写。

重写需要用户那一行的专业名词（命理术语、医学名词、行业规矩）当包袱时，用你最有把握的写，标 `【填：请确认】`，交给用户确认。

## 换人物

- 用户只点名换了一个人：他放进原片里「推销产品、给出答案」的那个角色。其余人物照原片身份，换成用户所在地方的人，写中性外形，交付时说明是你定的。
- 用户本人或品牌代言人当主角：用他真实的造型（招牌衣服颜色、发型、眼镜），观众才认得出。真人照片当参考图有些平台审核比较严，交付时提醒先用一段试。
- 本人出镜就问他要一段 10–15 秒、没有配乐的真声，接成 @audio1，他讲话的每一段都接上（写法见 `seedance-rules.md`「用真人的声音」）。用户有自己的口播片，就从里面挑一段剪出来：用 whisper 找一段连续口播，从两句之间的停顿切进切出。
- 用户有参考图：那张图就是 `@imageN`，提示词写「全片保持同一张脸、同一套衣服」。
- 用户没有图：先帮他写一段人物定妆描述（年纪、族裔、发型、衣服颜色款式、一个记忆点），建议他先用图片模型出一张定妆照再来生视频。
- 外形描述定下来就不要再改字，每一段原样贴。
- 原片里的真人、明星脸不要描述成「长得像某某」。
- 人物换了，年纪和身份要和剧情对得上。原片是小孩的戏，换成大人，动作和台词语气要跟着改。
- 原片有同一个人的不同年龄（小时候 / 长大后）：当成两个人物处理，各一张参考图，用同一个记忆点（同款外套、同一个发旋）让观众认得出是同一人。

## 换产品

- 一定要参考图。没有图的产品 Seedance 画不准。
- 对照原片找出产品出现的每一个镜头，逐个决定：这一镜产品怎么出现（手拿、桌上、背景、特写）。
- 原片产品是手机 App、网站这类屏幕内容：Seedance 画不出正确的界面。照 `seedance-rules.md` 的「要秀给观众看的屏幕」写：屏幕朝镜头、一片白光、举稳不动，出片后把真画面贴上去。
- 产品没有实体（线上课程、服务、会员、咨询）：找一个看得见的替身让它入镜，例如手机上的报名页、讲师本人、上课的画面、一本讲义。替身是屏幕的照上一条处理；是讲师本人的，就当换人物处理。
- 尺寸、拿法要跟着产品变：原片单手举手机，换成一大瓶饮料就不能照抄手势。
- **旧产品的字眼要从动作和台词里拿掉**：原片是裙子，动作写了「拉起裙摆」，换成裤子就要改成「拉一下衣角」；材质、部位名称都照新产品改，不然模型会画出四不像。
- 换衣服时加一句锁定：「衣服的图案、颜色、纹理照参考图，不要改」。
- 手尽量不碰产品，用手掌在旁边示意。
- 功效、价钱、数据只用用户给的，没给就留 `【填：…】`。

## 换场景

- 有参考图：`场景参考 @imageN`，再用一句话写清楚关键特征，防它跑偏。
- 没有图：写清地点类型、时间、天气、三样有辨识度的东西（例如「白天，马来西亚老街茶室，绿色百叶窗、大理石圆桌、吊扇」）。
- 灯光跟着场景重写，不要把原片的灯光硬搬到新场景。
- 原片换了几次场景，新版本也换几次，节奏才对得上。
- 本地化：用户在马来西亚，场景、衣着、称呼、货币都换成当地的，不要留着原片的校服、红领巾、街道样子。

## 改台词

- 字数跟着原片走。原片这一镜 2 秒讲 9 个字，新台词也控制在 8–10 个字，不然嘴型和节奏会垮。中文口播大约每秒 4–5 个字。
- 保留原片的句式和语气（反问、口头禅、重复出现的那句金句），换掉具体内容。
- 首尾呼应的句子（开头说一次、结尾再说一次）一定要保留呼应，这通常就是包袱。
- 用用户平常讲话的方式写，马来西亚用户用马来西亚华语的口语。

## 忠实复刻（都不换）

只给学员练手看懂用。

另一种做法是**视频编辑**：直接拿原片当 @video1，写「把 @video1 里的某某换成 @image1，动作完全照原视频，不要切镜头」。最像原片，但原片的真人脸、品牌会被带进来，侵权和审核风险最高，只在练手时用。

文字做法：提示词照原片写，但真人脸、品牌名、logo 用中性描述代替，交付时提醒：这是练习稿，原样发布会有抄袭和侵权的问题，正式发要换成自己的内容。
