# 审核避坑 和 出片后怎么改

## 一、写提示词时就避开审核

被拦下来不会告诉你是哪个字。写的时候先避开这些：

- **品牌、平台、真人名字**：原片里的品牌、App、明星、网红名字一律换成中性描述（「一个国学 App」「一位女歌手」）。用户自己的品牌名只放在台词里，画面里的 logo 走 seedance-rules「logo 要怎么进画面」。
- **借风格的说法**：「抖音爆款风」「旅行 vlog 风」「探店风」「某某导演式」「某某电视台级」这类借平台、作品、导演名字的写法，会被当成版权问题。改写成具体的画面：手持、近距离、自然光、快剪。
- **IP 和角色**：知名动漫、电影角色、品牌吉祥物，不要点名。
- **地缘、宗教、政治词**：国旗、领土、宗教人物不要放进画面描述；命理、风水类内容写成文化元素（九宫盘、铜钱），不要写成「预测」「保证」。
- **容易被误判的组合**：女性 + 暖色暗光 + 夜场类配乐（爵士钢琴、Lounge）容易被当成不当内容；英文运镜词（Dolly、Crane、Aerial）裸写可能被当成人名，中文提示词用中文运镜词。
- **真人脸**：见 seedance-rules「真人照片当参考」。

## 二、被拦了怎么找原因：二分法

1. 把提示词砍到 30–50 字的最简版（谁、在哪、做什么），参考图照接。过不了 → 问题在图（多半是真人脸），换图或改首帧模式。
2. 最简版能过，就一次加回一块（场景 → 动作 → 灯光 → 声音 → 台词），每加一块跑一次，卡住的那一块就是原因。
3. 把那一块里可疑的词换掉，再跑。

用最便宜的档位（快速、720p、最短秒数）来试，别用正式档位烧点数。

（审核词清单和二分法整理自 MapleShaw/seedance2.0-prompt-skill，MIT 授权。）

## 三、出片后怎么改

- **一次只改一个问题。** 脸崩和运镜不对同时出现，先改脸，确认好了再改运镜。同时改两样，不知道是哪一个改好的。
- **改一两个词就好**，不要整段重写。整段重写等于抽一次新卡，原本对的地方也会变。
- **先出小样**：先用快速档、720p 看构图和动作对不对，对了再用高清档出正式版。
- **提示词编版本号**：v1、v2、v3，每次改了什么写一行，学员才知道哪一个改动有用。
- **一段多出几条来挑**：AI 片段一次成功率不高，重要的段落可以出 2–3 条选最好的。这会花用户的点数，交付时讲清楚。
- **选一条当调色基准**：几段的色调不一样时，以最满意的那一段为准，其余后制往它调。

### 常见废片对照

| 出片问题 | 先改什么 |
|---|---|
| 脸不像本人 / 段和段变脸 | 主角排第一张参考图；加一张已确认像的脸部特写当第二张参考；每段外形描述一字不差 |
| 自己加了东西（眼镜、帽子） | 正面写那个部位的样子，不要写「没有…」 |
| 手指多、手变形 | 动作改小、改慢；手别去拿小东西，用剪接跳过接触动作 |
| 产品变形、logo 乱掉 | 产品图排前面并写「外形、颜色、logo 位置保持一致」；logo 改走图生图或后制 |
| 画面糊、塑料感 | 删掉 4K / 电影级；质感那行写清楚「不要磨皮、不要美颜」；检查素材图本身是不是影棚感 |
| 运镜断掉、乱切 | 一镜到底的段落每一拍写「镜头继续…」；「不要」里加「中途切镜头」；还不行就用原片当 @video1 |
| 运镜太猛、近景崩脸 | 近景不要大幅环绕；一次最多动两样 |
| 声音换错人 / 录音被播出来 | 每句台词标「用 @audio1 的声音说」，同段其他人写明不用；写明录音只定音色 |
| 品牌名念错 | 那一句后制换真声或配音 |
| 动作做太快、反应没出来 | 那一拍给更长的时间；写成 3–5 步的顺序 |
| 颜色一段一段不一样 | 选基准片，后制调色；灯光那行每段写一样 |

（「一次只改一个、改一两个词」「先出小样」整理自 liangdabiao/make-prompt-seedance2 和 ecom-video-seedance-prompt 的思路，用我们自己的话写。）
