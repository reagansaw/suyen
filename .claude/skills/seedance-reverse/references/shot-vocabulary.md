# 景别和运镜的叫法

写镜头表和提示词时统一用这些中文叫法。裸写的英文运镜词（Dolly、Crane、Aerial）在 Seedance 里有被审核误判成人名或品牌的情况，中文提示词用中文词。

## 景别

| 叫法 | 画面范围 | 常见用途 |
|---|---|---|
| 极致特写 | 眼睛、指尖、一滴水 | 放大情绪、质感 |
| 特写 | 一张脸、一件东西 | 微表情、关键道具 |
| 中近景 | 胸口以上 | 口播、对话 |
| 中景 | 腰以上 | 日常叙事 |
| 中全景 | 膝盖以上 | 肢体动作 |
| 全景 | 从头到脚 | 人物全貌 |
| 远景 | 人 + 大片环境 | 交代地点 |
| 过肩镜头 | 从一人肩后看另一人 | 对话正反打 |
| 双人镜头 | 两人同框 | 人物关系 |
| 主观视角 | 第一人称 | 代入感 |

## 机位角度

平视 · 俯拍（显得弱小）· 仰拍（显得有力）· 贴地低机位 · 正上方俯拍

## 运镜

| 叫法 | 怎么认 |
|---|---|
| 定镜 | 背景完全不动 |
| 缓慢推近 | 主体逐格变大，背景边缘往外走 |
| 缓慢拉远 | 主体逐格变小，露出更多环境 |
| 横摇 | 机位不动，画面左右转，背景横向滑过 |
| 直摇 | 机位不动，画面上下转 |
| 横向平移 | 机位左右移动，前后景有视差 |
| 跟拍 | 主体在画面里位置不变，背景一直往后跑 |
| 环绕 | 主体不动，背景绕着它转 |
| 手持 | 画面有轻微不规则晃动 |
| 升降 | 机位垂直升或降 |
| 甩镜 | 画面瞬间横向拉糊，常用来转场 |

节奏词：缓慢、平稳、轻微、渐进（温和）；快速、突然、猛地（强烈）。动作的六级强度梯子和更多中文安全运镜词（推轨推进、摇臂升降、斯坦尼康跟拍、贴地低机位…）见 `studio-brain-snapshot.md`。动作强度和运镜速度要配得上，不要写「轻柔地猛冲」这种自相矛盾的话。

## 转场

硬切（绝大多数）· 叠化 · 闪白 · 淡入淡出黑 · 甩镜转场 · 遮挡转场（东西挡住镜头再移开）· 匹配剪辑（前后两镜构图或动作对上）

转场大多是后制做的。提示词里只写「切到」，叠化、闪白、甩镜转场记进后制清单。

## 一段戏的作用

钩子 · 铺垫 · 冲突 · 转折 · 包袱 · 产品露出 · 证明 · 行动号召 · 收尾
