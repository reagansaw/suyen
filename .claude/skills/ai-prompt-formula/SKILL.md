# AI 提示词公式（Reagan 课件提炼版）

> **AI 不会猜心，只会执行指令。指令越清晰，结果越完美；指令越模糊，结果越垃圾。**
> 写文生视频提示词时，你不是在「写描述」，你是在**当导演**——提示词就是剧本，它决定风格、光影、镜头、节奏。同一个模型，专业提示词和随意描述的差距 = 「电影级」和「动画片」的差距。

---

## 1. 六要素万能公式（任何提示词都先套一遍）

| # | 要素 | 要写什么 | 例 |
|---|---|---|---|
| 1 | **身份** | 让 AI 扮演专业角色 | 「你是资深自媒体爆款文案导师」 |
| 2 | **场景** | 内容用在哪 | 「短视频口播文案」「小红书种草笔记」 |
| 3 | **对象** | 目标受众 | 「普通创业女性」「30+ 女性」 |
| 4 | **需求** | 核心任务 | 「写一段励志治愈文案」 |
| 5 | **要求** | 风格、情绪、字数、禁忌 | 「温柔有力量、接地气、不鸡汤、适合真人出镜」 |
| 6 | **格式** | 输出样式 | 「150 字左右纯口播文字」「分点列表」「对话式剧本」 |

反例 ❌「帮我写个文案」→ 没角色、没受众、没场景、没风格，产出必然千篇一律。

## 2. 七大专家叠加法（画面类提示词必用）

高阶提示词 = **一人调动七个顶级专家**。写画面/视频提示词时，在「身份」里按需叠：

1. **顶级导演**——镜头、氛围、叙事节奏，让画面有故事、有质感、有电影感
2. **中式美学专家**——国风意境、留白、韵味，内容高级耐看、自带气场
3. **光影专家**——明暗层次、柔光、通透感，告别灰蒙蒙死板画面
4. **结构专家**——构图、比例、层次、布局，画面干净整洁
5. **色彩专家**——统一色调、高级配色、视觉治愈
6. **传播专家**——贴合短视频传播逻辑，画面抓人、节奏舒服
7. **营销专家**——自带价值感、信任感，适合引流、种草、个人 IP

（做 Suyen 的东方美学 / 奇门遁甲气质时，1+2+3+5 是主力。）

### 2b. 具体头衔清单（课件原话，直接挑来填「身份」）

**导演类**——挑一个当主身份，决定整条片的调性：
- **顶尖级央视宣传片导演**／**文化宣传片导演** → 溯源片、品牌片、有分量的大片感（课件乐百氏水源溯源案例用的就是这个）
- **专业产品宣传片导演** → 产品特写、陈列、质感
- **店铺宣传片导演** → 门店人气、络绎不绝的客流
- **资深爆款短视频导师** → 口播逐字稿、钩子
- **资深个人 IP 文案导演** → 个人感悟、立人设

**专家类**——往主身份上叠 2–4 个，不要全叠：
- 美学专家 / **中式美学专家**（国风、留白、东方审美）
- **光影专家**、**灯光摄影**（明暗层次、柔光、通透感）
- 结构专家（构图、比例、层次）、色彩专家（统一色调）
- **产品陈列官**（东西怎么摆、货架秩序）
- **营销学专家 / 顶级营销专家 / 市场营销角度**（看完就想买）
- 传播专家（短视频分发逻辑）

**课件原话示范（溯源片）：**
> 「请你站在顶尖级的央视宣传片导演的角度……你是一个专业级的央视宣传片、文化宣传片的导演，同时你也是美学专家、光影专家、营销学专家。你站在这几个专家的角度，给我写一个 Seedance 2.5 能够看得懂的提示词，并且字符不能超过即梦最大的字符。」

**课件原话示范（门店片）：**
> 「请你站在顶级的营销专家的角度、市场营销的角度和产品陈列官的角度……我需要观众看完这个视频之后就很渴望来到我的店铺找我买鞋子。」

**课件原话示范（审 bug 那一轮）：**
> 「请你站在专业的产品宣传片导演的角度和产品陈列官的角度、灯光摄影的角度，重新审视一下这条内容，有哪些地方有 bug、哪些地方需要优化。」

### 2c. 每个 project 配一组固定专家（查表，别临场拼）

**规矩：每开一个新 project / 新片型，第一件事就是定下这一组专家，写进 `project/<name>/EXPERTS.md`，之后这个 project 所有提示词都用同一组。**
同一个 project 换来换去 = 味道不统一，片子就散了。

| Project / 片型 | 主身份（导演） | 叠加专家 | 要带出的味道 | 营销落点 |
|---|---|---|---|---|
| **suyen · 横版 16:9 广告**（C0001–C0048） | 顶尖级**央视宣传片导演** | 中式美学 ＋ 光影 ＋ 结构 ＋ 营销学 | 大气、有分量、权威，像台里播的 | 建立「奇门遁甲战略导师」可信度 → 报名 |
| **suyen · 竖版内容片 / reels**（C0049–C0060 玫红） | **资深爆款短视频导师** | 传播 ＋ 色彩 ＋ 中式美学（轻） ＋ 营销 | 近、快、像真人说话，不端着 | 钩子留人 → 完播 → 真声 CTA |
| **suyen · 1:1 上下 banner 版** | 专业**产品宣传片导演** | 结构（第一位，画面要塞得下上下 banner） ＋ 色彩 ＋ 传播 | 干净、信息一眼读完 | 信息流/朋友圈广告位点击 |
| **suyen · webinar / 长片** | **文化宣传片导演** ＋ 资深爆款短视频导师（开场 30 秒用后者） | 光影 ＋ 结构 ＋ 营销学 ＋ 传播 | 讲台感＋信任感，但开场要够钩 | 长留存 → 后段促单 |
| **suyen · B-roll / studio 画布** | 专业**产品宣传片导演** | **中式美学（主导）** ＋ 光影 ＋ 色彩 | 东方意境、留白、空镜有韵味 | 给正片换气、提质感（只当 B-roll） |
| **suyen · 照片 / 封面图**（suyenph） | 美学专家当主身份 | 光影 ＋ 色彩 ＋ 结构 ＋ 传播 | 第一眼高级、人物气场在 | 封面点击率 |
| **aigoal · 品牌 / 产品片** | 专业**产品宣传片导演** | 结构 ＋ 光影 ＋ 色彩 ＋ 营销学 ＋ 传播（**不叠中式美学**，科技向要利落） | 利落、现代、专业 | 产品可信 → 试用／咨询 |
| 门店 / 实体生意片（如有） | **店铺宣传片导演** | **产品陈列官** ＋ 营销学 ＋ 市场营销 ＋ 光影 | 人气旺、客流络绎不绝 | 看完就想到店 |
| 溯源 / 原料 / 来历片 | 顶尖级**央视宣传片导演** ＋ 文化宣传片导演 | 美学 ＋ 光影 ＋ 营销学 | 真实、厚重、可追溯 | 「原料安心」那一块促单 |

**另外两条通用的：**
- **审 bug 那一轮永远换一组人**：专业产品宣传片导演 ＋ 产品陈列官 ＋ 灯光摄影 —— 专门挑表情僵硬／AI 感／手脚畸形／门头文字畸形。不要用写稿那组人来审自己的稿。
- **叠 2–4 个就够**，全叠七个等于没重点；排在前面的权重最大，所以**把这个 project 最要紧的那一条排第一**（例：1:1 banner 把结构排第一）。

**`project/<name>/EXPERTS.md` 模板：**
```markdown
# <project> 专家配方
主身份：
叠加专家（按权重排序）：
要带出的味道：
营销落点（看完要做什么动作）：
禁忌：          # 例：不叠中式美学／不要 TVC 质感／不用绝对化用语
审 bug 用：专业产品宣传片导演 ＋ 产品陈列官 ＋ 灯光摄影
```

## 3. 文生视频提示词（Seedance 2.x / 即梦 / 可灵）

**骨架：**
> 请你站在【顶级 XX 宣传片导演 + 美学专家 + 光影专家 + 营销专家】的角度，我要拍一个【主题/用途】的视频：【场景与情节，写清人在干什么】。请给我生成一个【Seedance 2.5】能看得懂的提示词，**字符数不能超过【即梦】的最大字符限制**。

**必须写进提示词的维度**（照课件的清单）：视频风格 / 场景描述 / 环境描述 / 光影色调 / 人物角色与动作描述 / 运镜方式 / 运镜剪切 / **位置精准到秒** / 文字简洁。

**第二轮必做：找 bug 再优化**（这一步决定成片是否「不 AI 化」）
> 请你站在专业产品宣传片导演 + 产品陈列官 + 灯光摄影的角度，重新审视这条内容：哪些地方有 bug、哪些要优化？特别是人物细节——**面部表情舒展自然、不 AI 化、手脚没有任何畸形、门头/招牌文字不畸形**。重新梳理一版 Seedance 2.5 能看懂的提示词，字符不超过即梦上限。

## 4. 爆款 1:1 复刻（对标视频 → 可执行提示词）

拿到一条对标链接时：
> 帮我分析这个视频链接，提取出能直接用 AI 生成完整视频的提示词，内容包括视频风格、场景描述、环境描述、光影色调、人物角色与动作描述、运镜方式、运镜剪切，**位置精准到秒**，文字简洁，可以直接复制生成高度相似的视频。给我生成一个 Seedance 2.0 能听得懂的提示词。

复刻的颗粒度：**动作 / 神态表情 / 细节 1:1**。配合 skill `selling-video-craft` 的「复制成功 / 爆过的还会再爆」——先复刻结构和画面逻辑，再换成自己的人和产品。

## 5. 五大高频变现场景模板

**① 短视频口播逐字稿**
> 你是资深爆款短视频导师，请为我写一篇 3 分钟口播逐字稿。受众：【】；主题：【】；风格：真实、走心、有共鸣、接地气；要求：无书面化语言、适合真人出镜、层层递进、结尾升华；输出：完整纯口播文稿，无需修饰，直接朗读可用。

**② 朋友圈 / 私域文案**
> 你是资深私域文案操盘手，帮我写 5 条朋友圈文案。主题：【】；受众：普通粉丝/客户；风格：温柔真实、不硬广、有温度、生活化；每条 50 字以内，适合日常发布。

**③ 销售成交 / 沟通话术**
> 你是资深销售成交导师，针对【客户犹豫 / 咨询】场景，帮我写一段自然不尴尬的沟通话术。风格：真诚、专业、不推销、解决顾虑；适合一对一私聊成交。

**④ 个人 IP 感悟文案**
> 你是资深个人 IP 文案导演，结合普通人创业成长视角，帮我写一段真实走心的个人感悟文案。风格：真实治愈、有力量、引发共鸣、树立靠谱人设。

**⑤ AI 作图提示词**——套第 1 节公式 + 第 2 节专家叠加，再补光影/色彩/构图。

## 6. 五条避坑清单

1. **不要指令太短**——短句只能得到垃圾结果。
2. **不要多需求并行**——一次只让 AI 专注做一件事，混杂需求会分散注意力。
3. **不要不限定风格**——不限风格 = 默认通用口水话。
4. **不要不指定受众**——不分人群的内容注定没有共鸣。
5. **不要频繁改需求**——每次改都会重新生成、结果飘忽；一次把指令写清晰、逻辑闭环。

## 7. 本 repo 的落地约定

- 写口播/分镜的提示词，**身份固定补一句**：名字一律「林舒苑」，头衔「奇门遁甲战略导师」。
- 要求里固定加：**不出现医疗功效表述、不用绝对化用语**（和 `selling-video-craft` 第 2 节⑤审核对应）。
- AI 生成的素材只能当 B-roll 用；成片结构仍照 `project/suyen2027conference/HANDOFF.md`。
