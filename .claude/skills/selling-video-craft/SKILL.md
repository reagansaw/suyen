# 效果型影片方法论（Reagan 课件提炼版）

> 三条底层信念：**在成功的基础上复制成功 / 所有爆过的视频还会再爆 / 有效的事情重复做。**
> 一句话总纲：**把能出单的片子往死里拍。**

本技能只管「影片怎么想、怎么排」。具体工程（Remotion、渲染指令、字不盖脸等红线）照 `CLAUDE.md` → `project/suyen/HANDOFF.md`。

---

## 0. 先搞清楚在做哪一种片

| | 普通短视频 | 效果型（带货/转化）影片 |
|---|---|---|
| 目标 | 好看、有趣、涨粉 | **只为转化** |
| 拼什么 | 拼创意、拼情绪 | **拼画面、拼证据** |
| 看什么指标 | 完播率 | **ROI、商品点击、转粉** |

核心判断：**拍了产品 ≠ 能卖货；拍了结果 ≠ 能卖货。** 要「可视化的证据」。

Suyen 的片子属于效果型：横版广告 = 直接转化；竖版内容片 = 内容钩子带转化；webinar = 长效果型（见第 6 节）。

## 1. 好学生 vs 差学生（做之前自查）

| 差学生 ❌ | 好学生 ✅ |
|---|---|
| 先写脚本再改脚本 | **先定卖点，再配画面证据** |
| 抄同行口播文案 | 围绕卖点去拍/选素材 |
| 对着产品盒子空拍 | **效果镜头占大头** |
| 编导指令来自对标 | 素材排列组合、批量剪 |
| 拍一条投一条靠灵感 | **多版本赛马，用 ROI 说话** |

## 2. 流水线（这就是做片的工序，别跳步）

```
卖点拆解 → 口播文案 → 分镜脚本 → 出图出片 → 发布前审核
```

每一步的标准指令（直接拿去问模型，把【】换掉）：

**① 卖点拆解**
> 我要卖一款【产品/课程】。请先帮我把卖点拆干净：1. 列出 5 个核心卖点，每个用「一句话卖点 + 对应的痛点」表达；2. 标出哪个适合当开头钩子；3. 标出哪些说法有风险，需要弱化或加限定；4. 40 秒口播里讲透哪 2 个最合适。

**② 口播文案**
> 基于上面的拆解写一段 40 秒口播：1. 开头 3 秒抛一个常见误解；2. 中段讲透 2 个卖点，别堆参数；3. 结尾给一个明确动作；4. 纯口语，不用书面语、别用一串感叹号；5. 不出现医疗功效表述和绝对化用语。

**③ 分镜脚本**
> 把口播拆成 6 个分镜，每个包含：画面描述（产品怎么摆、光线、角度）、对应台词、单镜时长、转场方式。**多特写近景，少空镜。**

**④ 出图出片**（本 repo = Remotion 合成要求）
> 配音自然女声；**字幕关键词高亮**；BGM 压在人声下面；镜头切换紧凑。
> 本 repo 规矩：先 `scripts/stills.mjs` 出分镜检查图 → Reagan 点头 → 才渲染。

**⑤ 发布前审核**（逐条核查，列出命中项 + 修改建议）
1. 参数是否与原始资料一致，有没有模型自己编的
2. 是否出现医疗功效表述
3. 是否有绝对化用语
4. 画面和口播是否对得上
5. 字幕有无错别字、错位

## 3. 什么叫「有效画面」（选每一个镜头的唯一标准）

1. **一眼可捕捉**——用户 0.5 秒内看懂，不需要动脑。
2. **可视化**——直接展示结果，而不是靠嘴念参数。
3. **能刺激冲动**——变好看 / 解嘴馋 / 省麻烦，让人想立刻下单。

任何一个镜头三条都不中 → 删掉或换掉，别因为「画面好看」留着。

---

## 4. 万能三段框架：前 · 中 · 后

**前段 · 抓停留（3 秒黄金开头）**，任选一种开场：痛点 / 人设剧情 / 场景 / 价格福利。

**中段 · 核心转化（占整条片一半以上时长）**：引出产品 → 使用演示 → 效果展示 → 多场景·多人像展开。

**后段 · 做促单**：强调效果 / 讲性价比 / 讲原料·来历安心 / 限时福利 / 稀缺说明。

> 判断框架对不对，只看一个东西：**转粉、商品点击、ROI。**

### 中段怎么拍：使用 ＋ 效果
- **使用 = 把卖点展开**：多场景使用串联、多人像使用展开、**动作要慢要清楚**、紧接效果镜头。
- **效果 = 对比出来**：前后对比、局部对局部、借道具对比（如黑纸蹭妆）、人和人 / 人和物对比。
- **口诀：先拍结果，再拍使用，最后讲理由。**（剪的顺序也照这个来）

---

## 5. 三个大坑（新手最容易踩）

1. **死磕文案**——画面无效，文案再漂亮也带不动转化。先修画面。
2. **追求精致高级**——效果型要的是**真实感 + 效果清晰**，不是 TVC 质感。（和 HANDOFF.md「不要卡通动效、不要光晕代替厚度」一致）
3. **拍一条就判品不行**——**至少剪 3 个不同画面版本去赛马**，再下结论。

## 6. 套到本 repo 的几种片型

| 片型 | 前段 3 秒 | 中段（≥50%） | 后段 |
|---|---|---|---|
| 横版广告 C0001–C0048 | 痛点/身份开场，大字（放 `behind` 层） | 奇门遁甲怎么用 → 学员/现场效果对比 | 权威感 + 明确动作 |
| 竖版内容片 C0049–C0060 | 钩子 3 秒（玫红模板已有） | 好奇目录 → 每 5–8 秒换效果 → 1 个 B-roll | 9 秒真声 CTA |
| **Webinar / 长片** | 开场 30 秒 = 一条完整的「前段」：先抛误解或承诺结果，**不要先自我介绍** | 每 5–8 分钟一个小三段（讲点 → 案例演示 → 结果对比），中间插 B-roll 换气 | 最后 10% 做促单：效果复述 + 稀缺/限时 + 一个动作 |

Webinar 的额外要点（由上面原则推出，不是课件原文）：
- 每一段讲完必须有一个**可视化证据镜头**（截图、对比图、学员画面），光靠讲 = 无效画面。
- 长片同样要做「赛马」：换开场 30 秒剪 2–3 个版本，看留存曲线前 1 分钟的掉落。

---

## 7. 交片前最后三问

1. 前 3 秒有没有「一眼可捕捉」的东西？（静帧看，看得懂吗）
2. 中段够不够一半，且是**使用+对比**，不是空镜和口播？
3. 后段有没有**一个明确动作**？
4. 这一条有没有兄弟版本可以一起赛马？

配套：写给模型的提示词格式见 skill `ai-prompt-formula`。
