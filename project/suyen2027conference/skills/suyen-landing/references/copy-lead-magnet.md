## Opt-in 页（照这个顺序，不要跳）

### 0. 顶条（Suyen 页加的，一句戳痛）
- 怎么写：「X% 的人，因为…，导致…」——数字要有出处，没有就不用数字。
- 范例：「2027 丁未年，**同一年**，每个生肖的运都不一样」

### 1. 首屏（Hero）
- 模板：揭秘！【目标人群】准备好【实现什么结果】／让你可以在不用【XYZ】的情况下／也能在【多久】的时间内做到／【什么 End Result】／（呼吁行动的一句话）
- 怎么写：照 Suyen 首屏 4 样——小标（免费 + 是什么）→ 大字结果（短语，一行 ≤ 6 字）→ 一句「不用…也能…」→ 一句点名「尤其是…的你」；旁边放 lead magnet 封面；一个按钮。
- 范例：小标「免费领取 · 2027 十二生肖流年指南」／大字「1岁到100岁 / 运势指南」／「不用花钱算命，也能先看懂你和家人 2027 的运」／「尤其是要为全家做决定的你：自己、另一半、孩子、父母，一本看完。」／按钮「立即免费领取」

### 2. 痛点：这是你吗？
- 模板：因为没有用到你的产品/服务，导致出现什么问题，一直不能被解决而且还造成什么后果／不管你是【用户身份】，都可以透过【XX】得到【什么结果】
- 怎么写：3 个痛，标题讲后果、内文讲画面；最后一句「不管你是…，都可以透过…得到…」。
- 范例：①「年头冲，年尾才发现走错路」②「家人身体、孩子读书，出事了才知道要注意」③「每年都说要改运，却不知道从哪里开始」→「不管你是老板、上班族还是家庭主妇，都可以透过这本指南，先看清 2027 你家每个人的运势。」

### 3. 特点 / 好处 ×3
- 模板：特点/好处 1：因为这个好处，让你可以在不用【XYZ】的情况下，也能得到【什么结果】（×3）
- 怎么写：lead magnet 就写「里面有什么」——**只写真的有的**（照封面 / 目录）。
- 范例（照封面三格）：不同出生年份运势分析／事业 · 财运 · 感情 · 健康／幸运数字 · 颜色 · 能量建议

### 4. 为什么【XYZ】是最有效的：之前 / 之后
- 模板：之前 ❌问题1–4 → 之后 解决方案1–4 → （呼吁行动的一句话）
- 怎么写：一条对一条，之前灰卡、之后玫红卡，最后放按钮。
- 范例：之前「凭感觉做决定」→ 之后「先看清这一年适合冲还是守」……

### 5. 讲师
- 模板：在过去【多少年】的经验里，帮助超过【多少位】和你一样有【什么问题】的顾客，透过【你的什么服务】成功解决他们【什么问题】／名字／4 题：人们为什么要关心你是谁？做了多久？有什么突出结果？「现在我们正在教人们如何做完全相同的事情！点击下面了解更多信息」
- 怎么写：数字只用线上 suyen2027 页有的：近 20 年教学与咨询经验、1,000+ 场课程、数万名学员、2021 起每年举办战略大会、《运势大破解》2021–2027 年书作者、Supreme Fortunity Sdn Bhd 创办人兼首席执行官。

### 6. 真实案例
- 模板：名字 + 年龄 + 职业／Before 用之前有什么问题？After 用了之后有什么改善？怎么认识的？跟别的有什么分别？会推荐给谁？
- 怎么写：只用真的见证（线上页「企业家亲口分享」有：Mr Tim · HUACOMM、Desmond Tan · ALCP、Johnson · KLH Chemical、Rigine Seah · Azio International）。新见证要本人同意，没有就留【待补】。

### 7. 流程
- 模板：只要跑完【6】个流程，你将会得到【什么结果】！Step 1–6
- 怎么写：领取到用起来的步骤，最后一步接到下一个产品（3 天战略大会）。
- 范例：填资料 → WhatsApp 收到指南 → 找你的出生年份 → 看事业财运感情健康 → 照幸运数字颜色调整 → 想知道更多，来 3 天战略大会

### 8. Offer + 表单
- 模板：让你可以在不用【XYZ】的情况下…／原价 RM【XXX】／现在 Trial Package 只需要 RM【XX】
- 怎么写：lead magnet 写「免费领取」；**原价只写真的**。表单 3 栏：称呼、WhatsApp 号码、Email（选填）；按钮同全页那句；下面一行小字同意条款。

### 固定在底部：报名条
- 一行小字（「免费领取 · WhatsApp 马上收到」）+ 按钮（同一句）。

## Thank you 页（Canva 模板没有，我们的做法）

1. 大字「✓ 领取成功」+ 一句「指南已经发到你的 WhatsApp」（照实际的发送方式写）
2. **3 步下一步**：① 打开 WhatsApp 收指南（没收到怎么办）② 加入 Community（真的链接）③ 下一步产品（3 天战略大会 / 讲座，真的报名链接）
3. 老师一句话（照她真的讲过的话，例：「以易经智慧洞察趋势，以风水趋吉避凶，以奇门战略布局人生。」）
4. 一个主按钮：加入 Community 或报名下一步（只放一个最重要的）
