# Webinar 报名后提醒（aigoal beats）

> Reagan 11-18：报名 → 第一封带 YES 按钮 → 回 YES 才发直播链接 + WhatsApp Community（里面有小礼物）→ 24 小时前（YES 我会出席）→ 3 小时前 → 开始了。
> 这是 aigoal webinar 漏斗本来就有的「beats」，不用自己建流程，只要换文字、开按钮。
> 代码出处：aigoal-ops `funnelTemplates.js`（REMINDER_TPL、beatButtonConfig）、`waTemplatePack.js`（PACK）、`webinarFunnel.js`（handleReplyGate）、`server.js` `/api/funnels/:id/reminders`。11-18 读的版本。

## 1. 5 条讯息对应哪一拍

| # | beat | 几时发 | 按钮 | 叫他做的 1 件事 |
|---|---|---|---|---|
| 1 | `A_GATE` | 报名当下 | 快速回复「YES」 | 回 YES |
| 1b | `AY` | 他回 YES 的那一刻 | 无（普通文字，不用审） | 点直播链接 ＋ 进 Community 领礼物 |
| 2 | `B` | 开始前 24 小时 | 快速回复「YES 我会出席」 | 按按钮 |
| 3 | `C` | 开始前 3 小时（`h:-3`） | 进场链接（URL） | 点链接 |
| 4 | `C2` | 开始的那一刻（`h:0`） | 进场链接（URL） | 点链接 |

- 活动后追单 `F1/F2/F3` 默认关掉（`false`）。要卖东西才开，而且那不是这份 skill 写的。
- 系统怎么跑：
  - `A_GATE` 发出后，客人被标成「等 YES」。
  - 他按按钮，或打 yes / ok / 好 这种短短的肯定回覆，系统就自动发 `AY`，再贴 `yes_confirmed` 标签。
  - `B` 设成快速回复后，他按「YES 我会出席」，系统会**再发一次 `AY`**（链接 ＋ Community）。所以 `B` 不用放链接，写「我把进场链接再发你一次」就好。
- 这跟 7 条预热讯息不一样。预热是发给旧名单，每条不同关键字；这里是报名的人，`A_GATE` 和 `B` 都用 YES 没关系，系统按拍分得出来。

## 2. 变量（写在文字里，系统发的时候换掉）

| 变量 | 换成什么 |
|---|---|
| `{name}` | 他填的称呼 |
| `{zoom}` | 进场链接（Zoom / FB 群组 / YouTube）。系统会换成追踪短链接，谁点了看得到 |
| `{community}` | WhatsApp Community / 群组链接，也是追踪短链接 |
| `{time}` | 活动时间。⚠️ 现在发出去是「2026-12-01 21:00」这种原始格式，不好看 |

**日期怎么写**：
- 一次性的活动：直接写死「12月1日（星期二）晚上 9:00」，不用 `{time}`。系统会出黄色警告「疑似写死了日期」，可以不理。
- 每周滚动的 webinar：用 `{time}`，不要写死。

## 3. 每条的骨架

全部照 SKILL.md 第 3 段的写法铁律（一句一行、每条 1 个行动、署名两行）。

**1 · A_GATE（报名当下）**
1. 「嗨 {name}，收到你的报名了 🙏」
2. 活动名 ＋ 日期时间 ＋「位置帮你留好了」
3. 这场讲什么（2–3 行，用落地页上的讲题）
4. 「回我一个 YES，我马上把直播链接发给你，还有一份小礼物要送你 🎁」
5. 为什么要回（1–2 行）：「你回了我才知道号码是通的，当天的提醒你才收得到」
6. 署名
- **不可以放 `{zoom}`**（系统会警告）：链接是回 YES 的奖励。

**1b · AY（回 YES 后）**
1. 「太好了 {name} 🙌」
2. 📍 直播在哪 ＋ `{zoom}`
3. 🎁 小礼物在哪领 ＋ `{community}`。**写清楚礼物是什么**，不知道就写【待补：小礼物】
4. 日期时间「见」＋ 叫他准备什么（纸笔、最担心的 1 件事）
5. 署名
- 这条有两个链接，是 Reagan 指定的，算例外。**一定要有 `{zoom}`**（系统会检查）。

**2 · B（24 小时前）**
1. 「嗨 {name}，明天晚上就是了。」
2. 活动名 ＋ 日期时间
3. 明天会讲到的 1 件事（2–4 行），用落地页的讲题
4. 「不是理论，是你听完就可以做的东西。」
5. 「会来的话，按下面『YES 我会出席』👇 我把进场链接再发你一次。」
6. 署名

**3 · C（3 小时前）**
1. 「嗨 {name}，再过 3 个小时，【活动名】就开始了。」
2. 今晚来的人会知道什么（3–4 行，只讲「会知道 / 会看懂」）
3. 「现在先把…打开，X 点直接进来 👇」＋ `{zoom}`
4. 「里面见！」＋ 署名

**4 · C2（开始了）**
1. 「嗨 {name}，我们开始了 🔥」
2. 「【活动名】现在直播中。」＋ 一开场在讲什么（1–2 行）
3. 「还没进来的话，现在点 👇」＋ `{zoom}`
4. 署名
- 短，100 字左右。

## 4. Meta 模板规则（系统会挡的）

- 文字不可以用变量开头或结尾：开头写「嗨 {name}，」可以；署名放最后，就不会用变量结尾。
- 两个变量不可以连在一起，例如 `{zoom}{community}`。
- 每条 ≤ 1,000 字（系统的上限）。照写法铁律写，每条 ≤ 400 字。
- 按钮文字 ≤ 25 个字符，最多 3 个快速回复。
- 这 5 拍都算 Marketing 类。`AY` 是回覆后 24 小时内发的普通文字，不用审；其他 4 拍要审。
