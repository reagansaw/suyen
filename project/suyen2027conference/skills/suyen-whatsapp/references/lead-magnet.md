# Lead Magnet 领取后讯息（aigoal lead magnet beats）

> Reagan 11-18：lead magnet 要「发东西」＋「进群」。
> 系统出处：aigoal-ops `funnelTemplates.js`（M1_GATE / M1Y / M2 / M3、reminderPlanLeadMagnet、BEAT_OFFSETS）、`webinarFunnel.js`、`server.js` `/api/funnels/:id/reminders`。11-18 读的版本。

## 大多数 lead magnet 是怎么做的

做得好的 lead magnet 跟进，几乎都是这 4 步：

1. **马上交付**：领了几分钟内就要收到。拖越久，他越忘了自己领过什么，打开率掉很多。
2. **先要他回一个字**（WhatsApp 才有的做法）：回了，就知道号码是通的；24 小时免费回覆窗也开了；他也习惯「这个号会跟我讲话」。
3. **推他真的去看**：大部分人领了不看。所以第二条不卖东西，只叫他先看最有用的那一页，拿到一个小收获（quick win）。看了有收获的人，才会信下一步。
4. **软软地带到下一步**：活动、讲座、课程。先问他要不要（回一个字），不硬塞链接，不报价钱。

**进群放在哪**：跟资料一起发（第 1b 条），写成「看完想知道更多，老师的 Live 和每月提醒都在 Community」。资料是主角，群是附带。不要把资料藏在群里（「进群才拿得到」），会掉很多人。

Suyen 的感谢页（suyen-landing 的 `yunshi-guide`）也是这个顺序：收指南 → 加入 Community → 来战略大会。讯息跟着同一个顺序走。

## 1. 4 条讯息对应哪一拍

| # | beat | 几时发 | 叫他做的 1 件事 |
|---|---|---|---|
| 1 | `M1_GATE` | 领取当下 | 回 **YES** |
| 1b | `M1Y` | 他回 YES 的那一刻 | 点开资料（＋ 顺手进 Community） |
| 2 | `M2` | **用户定**（领取后几小时 / 几天） | 回一个字，例：**看了** |
| 3 | `M3` | **用户定**（要比 M2 晚） | 回一个字，例：**想知道** |

- 要开 YES 这一步，`reminders.json` 填 `"reply_gate": true`，第 1 条就从 `M1` 换成 `M1_GATE`。不开的话，第 1 条直接发资料（`M1`），没有 1b。**建议开。**

### M2、M3 几时发：问用户，不要自己定（Reagan 11-18）

先问：**「你的号码是官方号（WABA）还是扫码号？」**

- **官方号（WABA）→ 建议 M2 设在 24 小时内**，例如领取后 20 小时。
  - 他回 YES 之后有 24 小时的免费回覆窗。窗内可以发普通文字：不用 Meta 审、不收模板费、不怕模板被拒。
  - 讲给他听的限制：
    - 窗是从**他回 YES 那一刻**算起，系统的时间是从**领取那一刻**算起。他领了很久才回 YES，窗会比较短；他没回 YES，就不在窗内，这条要有审过的模板才发得出。所以设 20 小时左右，留一点空间。
    - 太早发（例如 2 小时），他可能还没打开资料，M2「你翻了吗」就不准了。M2 的文字要改成「先看第 X 页就好」这种推他去看的口气。
  - M3 通常在窗外，要送审。
- **扫码号 → 没有 24 小时窗的问题**，照他想要的节奏就好。常见是 M2 在 1–2 天后，M3 在 4–7 天后。提醒他：一次发很多人容易被封号。

写法：`"beats": { "M2": { "h": 20 }, "M3": { "h": 96 } }`。
- 单位是小时，可以填任意数字（系统收 1–720 小时，也就是最多 30 天）。
- 不填就是系统默认（M2 48 小时、M3 120 小时）。
- 不要 M3 就填 `"M3": false`。
- ⚠️ **系统限制**：现在只有 webinar 的拍（A_GATE / AY / B / C / C2）能设按钮，`M1_GATE` 设不了「YES」快速回复按钮，客人要自己打 YES（打 yes / ok / 好 也算）。要按钮，就要请 aigoal 开发加。

## 2. 变量

| 变量 | 换成什么 | 哪里设 |
|---|---|---|
| `{name}` | 他填的称呼 | — |
| `{magnet}` | 资料的下载链接（PDF / Google Drive / 网页） | `reminders.json` 的 `magnet_url`，一定要 `https://` 开头 |
| `{community}` | WhatsApp Community 链接（追踪短链接） | `reminders.json` 的 `community_url` |

- 资料要是**一条打得开的链接**：PDF 放 Google Drive 要设「任何人有链接都能看」，自己先用没登入的手机打开试一次。
- 系统发的是链接，不是 WhatsApp 里的 PDF 档。要配图，可以放资料的封面（见 `photo.md`）。

## 3. 每条的骨架

全部照 SKILL.md 的写法铁律（一句一行、每条 1 个行动、署名两行、不编、不保证结果、不吓人）。

**1 · M1_GATE（领取当下）**
1. 「嗨 {name}，你要的《资料名》帮你准备好了 🙏」
2. 这份资料里有什么（2–3 行，用落地页的卖点）
3. 「回我一个 YES，我马上把领取链接发给你 📥」
4. 为什么要回（1–2 行）：「你回了我才知道号码是通的，之后老师的提醒你才收得到」
5. 署名
- **不可以放 `{magnet}`**：链接是回 YES 的奖励。

**1b · M1Y（回 YES 后）**
1. 「太好了 {name} 🙌」
2. 📥「《资料名》在这里，点开就能看：」＋ `{magnet}`
3. **先看哪里**（1–2 行）：「先翻到你自己生肖那一页」。给他一个马上做得到的小动作。
4. 👥 Community（2–3 行）：「老师的 Live、活动和每月提醒，都先在 Community 公布：」＋ `{community}`
5. 「看的时候有问题，直接回我这里。」＋ 署名
- 两个链接是例外（Reagan 指定：发东西 ＋ 进群）。资料放前面，群放后面。

**2 · M2（用户定的时间）· 推他去看**
1. 「嗨 {name}，那份《资料名》你翻了吗？」
2. 一个最多人漏看的地方（2–3 行）：「很多人只看自己生肖，漏了…」。**只讲资料里真的有的**。
3. 一个小收获（2–3 行）：看了那一段会知道什么。
4. 「看了的话，回我一个『看了』，告诉我你最有感觉的是哪一句 👇」
5. 署名
- 不卖东西、不放活动链接。

**3 · M3（用户定的时间）· 软软地带到下一步**
1. 「嗨 {name}，想问你一件事。」
2. 资料看的是什么，没讲到什么（2–3 行）：「指南看的是生肖的大方向；你自己今年的局、哪个月要防，指南里没有。」
3. 下一步是什么（2–3 行）：活动名、免费还是收费、日期（有才写）。
4. 「想知道的话，回我『想知道』，我把资料发给你 😊」
5. 「暂时不需要也完全 OK，指南留着慢慢看。」＋ 署名
- 不放价钱。他回了，就是负责人（或 bot）接手的名单。
- 还没有下一步的活动，M3 就关掉（`"M3": false`），不要硬写。

## 4. Meta 模板规则

跟 webinar 一样（见 `webinar-beats.md` 第 4 段）：
- 不用变量开头或结尾，两个变量不可以连在一起。
- 每条 ≤ 400 字。
- 都算 Marketing 类。
- `M1Y` 是回覆后 24 小时内发的普通文字，不用审；`M1_GATE`、`M2`、`M3` 要审。

## 5. 交什么

在 `whatsapp/<资料名>/lead-magnet/` 里放：
- `1-M1_GATE.txt`、`1b-M1Y.txt`、`2-M2.txt`、`3-M3.txt`
- `reminders.json`：
  ```json
  {
    "reply_gate": true,
    "magnet_url": "<资料链接>",
    "community_url": "<WhatsApp Community 链接>",
    "overrides": { "M1_GATE": "…", "M1Y": "…", "M2": "…", "M3": "…" },
    "media": { "M1_GATE": "<封面图 url>" },
    "beats": { "M2": { "h": <用户定> }, "M3": { "h": <用户定> } }
  }
  ```
- 放进系统：照 `aigoal-setup.md`。差别是漏斗类型是 `leadmagnet`（`POST /api/funnels/<id>/kind` 填 `{ "kind": "leadmagnet" }`），**没有活动时间**那一步；送审的拍是 `M1_GATE`、`M2`、`M3`。

先交第 1 条和第 1b 条给负责人看口气，对了再写 M2、M3。
