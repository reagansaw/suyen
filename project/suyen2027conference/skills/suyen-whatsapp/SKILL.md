# Suyen WhatsApp 讯息 · 7 条预热公式

> Reagan 11-13：给了一组 7 条的 WhatsApp 讯息（个人 IP 分享会，11-03 到 11-11）当公式，「做一个 skill 可以生成这个 WhatsApp template」。
> 冲突时：Reagan 在对话里的最新指示 > 这份。

这套讯息是发给**已经留了 WhatsApp 的人**（报名了、领过 lead magnet、旧名单），目的只有一个：**让他当天真的出现**。不在讯息里卖东西、不报价钱。

## 1. 先问清楚 6 样（缺了就问，不要自己编）

1. **活动**：名字、日期、几点开始、线上还是现场、进场链接（Zoom / 社群）。
2. **发给谁**：哪一种人（做生意的 / 打工的 / 旧学员…）＋ 他最烦的 1 件事。
3. **老师自己的故事**（第 2 条用）：她当年为什么开始、有哪一幕很难受。**一定要她真的发生过的**，没有就留【待补：老师的故事】。
4. **1 个真学员 / 真客人的案例**（第 3 条用）：谁、什么行业、原本怎样、后来怎样。要本人同意。没有就留【待补：案例】。
5. **有没有影片可以放**（第 2 条的链接）：没有就不放链接，只叫他回 OK。
6. **谁署名、用哪个号发**：署名默认「—林舒苑 Master Suyen」；官方号还是扫码号由负责人决定（见 `references/sending.md`）。

## 2. 7 条的日程（D = 活动当天）

| # | 哪一天 · 几点 | 这条做什么 | 叫他做的 1 件事 |
|---|---|---|---|
| 1 | D-8 · 晚上 8:30 | **问痛**：讲一个他遇过的委屈画面，告诉他「问题不在你」 | 回 **YES** |
| 2 | D-6 · 晚上 8:30 | **我的故事**：老师当年难受的一幕 → 她做了什么决定 | 看影片，回 **OK** |
| 3 | D-4 · 早上 11:00 | **学员案例 ＋ 第一次公布活动**（日期、时间、免费） | 回 **JOIN** |
| 4 | D-2 · 早上 8:30 | **比喻 ＋ 破误会**：「不是叫你…，是…」＋ 提醒日期 | 设 reminder |
| 5 | D-1 · 晚上 8:30 | **一个假设题**：「如果明天…，你…吗？」 | 回 **Ready** |
| 6 | D · 早上 10:30 | **今晚就是了**：现在不做会怎样 ＋ 进场链接 | 点链接 |
| 7 | D · 开场前 1 小时 | **最后提醒**：来的人和没来的人 ＋ 进场链接 | 点链接，「里面见」 |

- 前 2 条**不提活动**，只聊他的事；第 3 条才公布。
- 时间不够 8 天：先砍第 2 条，再砍第 4 条；第 1、3、6、7 条不能砍。
- 几天的活动：第 2、3 天开场前 1 小时各补一条短的，照第 7 条写。

每一条的骨架、每一段写什么，在 `references/formula.md`。**写之前先读**。

## 3. 写法铁律

- **一句一行**，一行手机上不换行（最多 18 个字左右）。2–4 行一段，段和段之间空一行。
- **每条只叫他做 1 件事**（回一个字 / 点一个链接）。不要又回 YES 又点链接又填表。
- **每条结尾留一个钩**：「下次我给你看…」「明天晚上我会告诉你…」。第 7 条不用。
- **「不是…不是…是…」**：每条最多用一组，用来破他的误会。
- 开头叫名字只用在第 1、5、6 条（「嗨【名字】」），不要每条都叫。
- 表情每条最多 2 个，放在叫他行动的那一行（👇 😊 🔥）。
- 每条 150–350 个字。超过 400 就删。
- 回覆的关键字用英文大写（YES / OK / JOIN / Ready），**一条一个，不要重复用同一个**——负责人才分得出他回的是哪一条。
- 马来西亚华人口语：「set 好 reminder」「zoom link」这种可以用；不用「赋能」「助力」「干货满满」。
- 名字永远是「林舒苑」/ Master Suyen；不提 Allianz。

## 4. 不可以做的

- **不编故事、不编案例、不编数字**。老师的故事和学员案例只用真的，没有就留【待补】交给负责人。
- **不保证结果**：不写「来了就会赚钱 / 转运」。只写他会看懂什么、带走什么。
- **不拿命运吓人**：可以讲「没看清就做决定，容易走冤枉路」；不可以讲「不来你明年会出事」。
- 不在这 7 条里报价钱、卖 VIP（那是报名后那一页和活动当天的事）。
- 链接只放真的；没有就写【待补：Zoom 链接】，不要放猜的网址。

## 5. 交什么

一个资料夹 `whatsapp/<活动名>/`，里面：
- `01.txt` … `07.txt`：一条一个档，直接可以复制贴上。名字的位置写【名字】。
- `README.md`：一张表（第几条、几月几号几点发、叫他回什么）＋ 还没补的【待补】清单。

先交**第 1 条和第 3 条**给负责人看，口气对了才写完 7 条。

## 6. 交件前检查

- [ ] 7 条的日期是照真的活动日期倒算的，星期几对过日历
- [ ] 每条只有 1 个行动；回覆关键字 7 条里没有重复
- [ ] 没有超过 18 个字不换行的句子；每条 ≤ 400 字
- [ ] 老师故事、学员案例是真的，或者清楚写着【待补】
- [ ] 没有保证结果、没有吓人的句子、没有价钱
- [ ] 活动名、日期、时间 7 条写的一样
- [ ] 第 6、7 条有进场链接（或【待补】）
- [ ] README 里列了所有【待补】
