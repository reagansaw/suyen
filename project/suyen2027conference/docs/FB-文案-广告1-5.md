## UTM

规则：全部小写、不用中文、不用空格。

| 参数 | 值 |
|---|---|
| `utm_source` | `facebook` |
| `utm_medium` | `paid_social` |
| `utm_campaign` | `suyen2027_qimen` |
| `utm_content` | `adNN_题目_版式`（版式：`169` 横版 / `1x1` 方形） |
| `utm_term` | 受众名称（可选，例如 `owners_my_35-55`） |

在 Meta 广告的 **URL parameters** 栏贴下面这串（不用加 `?`）。网址本身放在 Website URL 栏。

| 广告 | 横版 16:9 | 1:1 |
|---|---|---|
| 广告1 | `utm_source=facebook&utm_medium=paid_social&utm_campaign=suyen2027_qimen&utm_content=ad01_jingli_169` | `…&utm_content=ad01_jingli_1x1` |
| 广告2 | `utm_source=facebook&utm_medium=paid_social&utm_campaign=suyen2027_qimen&utm_content=ad02_fanshen_169` | `…&utm_content=ad02_fanshen_1x1` |
| 广告3 | `utm_source=facebook&utm_medium=paid_social&utm_campaign=suyen2027_qimen&utm_content=ad03_duishou_169` | `…&utm_content=ad03_duishou_1x1` |
| 广告4 | `utm_source=facebook&utm_medium=paid_social&utm_campaign=suyen2027_qimen&utm_content=ad04_huoban_169` | `…&utm_content=ad04_huoban_1x1` |
| 广告5 | `utm_source=facebook&utm_medium=paid_social&utm_campaign=suyen2027_qimen&utm_content=ad05_yacuo_169` | `…&utm_content=ad05_yacuo_1x1` |

1:1 那一栏的 `…` 跟横版前面一样，只换最后的 `utm_content`。

**懒人版（Meta 动态参数，一串通用）**：广告名照上面 `utm_content` 取名，就可以每支都贴同一串。
```
utm_source={{site_source_name}}&utm_medium=paid_social&utm_campaign={{campaign.name}}&utm_content={{ad.name}}&utm_term={{adset.name}}
```
- `{{site_source_name}}` 会自动填 `fb` 或 `ig`，可以分开看 Facebook 和 Instagram。
- campaign / ad set / ad 名字也要用英文小写、不留空格。
