# 竖版内容片：首页 1 帧海报 + 下 banner（Reagan 2026-11-02 定稿）

以后**每一支竖版内容片**（内容①②③…）出片前都照这个加。内容① v8、内容② v4 已做。

## 版式（1080×1920）

| 位置 | 内容 |
|---|---|
| **第 1 帧**（只有 1 帧，约 0.033 秒） | 这支的「首页海报」满屏。**不放 banner**。不淡入淡出，第 2 帧直接是影片 |
| **第 2 帧起，整支** | 影片原样 + 最下面贴 2027 战略大会 banner（`remotion/public/suyenc/banner_bottom.webp`，2000×530 缩成 1080 宽，约 286 高，贴底） |

- 为什么只 1 帧：给发帖 / 文件缩略图当封面用，Reagan 不要观众看到一秒的静止画面。
- 海报是 3:4（1086×1448），要铺满竖屏：放大 1.15–1.22 倍，从左边起裁 1080 宽，**让左边大字不被切、人脸完整**；下面不够的高度用海报最下面那一条**镜像**补满。**不要模糊底**（Reagan 否定过）。
- banner 只盖在影片最下面。内容片的字幕在 y≈1100–1430、片尾留言框在 banner 上方，不会被挡；其他画面靠下的话要检查。
- 声音、长度不动（加完跟原片一样长）。

## 做法

```bash
# 在 repo 根目录。海报图（每支一张，Reagan 给）；--phone 顺便出手机版
python3 pipeline/cover_banner.py <成片.mp4> <海报.png> <输出.mp4> [--scale 1.22] [--x 35] --phone
```

- `--scale` / `--x` 看海报调：左边大字不能被切、她的脸要完整。
  - 内容①（人在右、字在左偏窄）：`--scale 1.22 --x 35`
  - 内容②（人更靠右边）：`--scale 1.15 --x 58`
- 交片前截第 1 帧、第 2 帧和中段各一格看：第 1 帧是海报（没 banner）、第 2 帧是影片（有 banner）。
- 命名：`Suyen-内容N-题目-竖版-vX-首页+banner.mp4`，手机版加 `-手机`（crf 25、maxrate 6M）。放 `~/Downloads/`。
