# 留言 → 自动回覆 → 自动私讯：为什么这样设计

> 资料：Meta 官方 Private Replies / Quick Replies 页、ManyChat 的 comments automation 和社区讨论、几家 Instagram API 服务商（Gupshup、hooksend、Planoly 等）的文件，11-18 查的。
> aigoal 的实际做法：aigoal-ops `social.js`、`automations.js`、`server.js`（11-18 读的版本）。

## 1. 整条路

```
贴文：「留言『指南』，我私讯发给你 📩」
   ↓ 他留言「指南」
① 公开回覆他的留言（4–6 句随机挑一句）：「私讯你了，记得看 Requests 📩」
② 第一条私讯（private reply）：一段话 ＋ 按钮「发给我 📩」
   ↓ 他点按钮（＝他回覆了，24 小时窗口打开）
③ 第二条私讯：交付 ＋ 按钮「📥 领取指南」（打开网址）＋「💬 加入 WhatsApp」（打开网址）
```

这是 ManyChat 那一类工具最常见的做法，大部分做 comment-to-DM 的教练、创作者都这样跑。

## 2. 为什么用按钮，不用 quick reply

**Instagram**
- 留言后，系统只能私讯他**一次**（叫 private reply），而且要在留言后 7 天内。之后要**等他回覆**，才可以在 24 小时内继续发。
- 所以第一条私讯一定要有一个「他一定看得到、点了就算回覆」的东西。
- **按钮**（button template 里的 postback 按钮）：一直留在讯息上，手机、网页都看得到。点了，系统收到回传，就算他回覆了。
- **Quick reply**：
  - Instagram 网页版、电脑版**不显示**。
  - 键盘打开时会被盖掉；他打了别的字，quick reply 就消失。
  - 有服务商反映 quick reply 跟按钮放在一起，Instagram 会报错（Facebook 不会）。
- 结论：**IG 用按钮。**

**Facebook Messenger**
- Reagan 说 Messenger 的 quick reply 有时有 bug。网上也有：Android 不显示、关掉对话再开才出现。ManyChat 的人员（2025-09）叫大家先把 quick reply 换成按钮。
- 结论：**Messenger 也用按钮。**

**按钮的规格（IG 和 Messenger 一样）**
- 最多 3 个。
- 文字 ≤ 20 个字符，超过会被截掉（不会报错，所以要自己数）。
- 两种：postback（点了回传给系统，用来继续对话）、web_url（打开网址）。
- 讯息文字 ≤ 640 个字符。

⚠️ Meta 官方的 private reply 页面只示范纯文字，「第一条私讯带按钮」是第三方文件写的。aigoal 现在就是这样发（`social.js` 把按钮转成 button template，跟 private reply 一起送）。第一次用，**一定要自己测一次**。

## 3. 为什么第一条私讯不直接给链接

- 直接给链接也可以，一条就交付完。但他点的是网址，**不算回覆**，24 小时窗口没开：之后不能再私讯他，也拿不到他的 WhatsApp。
- 先点「发给我」再给链接，多一步，但：
  - 他点了，窗口开了，可以发第二条（交付 ＋ WhatsApp）。
  - 系统可以帮他贴标签（例：`ig_指南`），之后知道谁拿过。
- 这一步要**轻**：不问问题、不叫他填资料，只是一个按钮。问「你做什么的？」才给，是骗人，会被记住。
- 负责人想要一步到位，就把 dm-1 改成直接给链接按钮（web_url），没有 dm-2。讲清楚代价：之后不能再私讯他。

## 4. 公开回覆为什么要轮流

- 同一句话回几百个留言，Meta 可能当成垃圾讯息（ManyChat 社区的建议，不是官方条文，但大家都这样做）。
- 公开回覆也让贴文看起来有人在回，留言会更多。
- 不放链接：公开回覆放链接容易被限流，也会让人不用留言就拿走。

## 5. Meta 的限制（写 README 时提醒负责人）

| 限制 | 内容 |
|---|---|
| 一次 | 每个留言只能私讯一次（aigoal 记最近 3,000 个留言 ID 防重复） |
| 7 天 | 留言 7 天后就不能私讯了（aigoal 只在「补发旧留言」时检查） |
| 24 小时 | 他回覆（点按钮）之后 24 小时内才能继续发 |
| 速度 | aigoal 默认每个专页每小时最多 20 条私讯（可调 1–100），超过的排队慢慢发 |
| 同一个人 | 同一个链条，同一个人 24 小时内只跑一次 |
| 收不到 | 他的隐私设定挡讯息请求、留言被删，私讯就发不出去 |
| Requests | 没关注专页的人，私讯会进「讯息请求」，所以公开回覆要提醒他去看 |
| 账号 | IG 要是专业账号（商业 / 创作者），接上 Facebook 专页 |

## 6. 之后要不要 follow up（问用户）

先把规矩讲给他听，再让他选。

**规矩（IG 和 Messenger 一样）**
- 自动私讯只能在他**最后一次互动后 24 小时内**发。点按钮、回一个字都算互动，每互动一次就重新算 24 小时。
- 超过 24 小时，就不能再自动发推广讯息。Meta 只留一个「真人客服」的例外（human agent，7 天内，**一定要真人亲手回**），不能拿来做自动跟进。
- 所以私讯里的跟进，最多就是「24 小时内再一条」。

**3 个选项**

| 选项 | 怎么做 | 适合 |
|---|---|---|
| 不追（建议，有领取页时） | 第二条私讯就结束。他在领取页留了 WhatsApp，之后由 `suyen-whatsapp` 的 lead magnet 流程（C 类）跟进 | 有领取页、要拿号码 |
| 24 小时内追 1 条 | 点按钮后约 20 小时：「领到了吗？还没打开的话再点一次 👇」＋ 网址按钮 | 没有领取页，只发资料 |
| 追 1 条 ＋ 再一个回传按钮 | 20 小时那条带一个回传按钮（例：「我看了 ✅」），他点了又有 24 小时，再发一条带到下一步 | 想在 IG / Messenger 里多聊一步 |

- 设 20 小时，不要贴着 24 小时：排程会有几分钟误差，过了 24 小时就发不出去。
- follow up 不叫他重新留言、不报价钱、不骚扰：最多 2 条。
- 他点了网址按钮**不算互动**，只有回传按钮、回覆文字才算。

## 7. 「要先关注才发」

很多工具有这个选项（关注了才发资料），可以涨粉，但会掉人。**aigoal 现在没有这个功能**，所以不写。负责人要的话，记下来请 aigoal 开发。
