# 1:1「上下 banner 夹影片」格式（2026-11-02 定稿）

Reagan 点头的版本（广告1 v-final）。以后 Suyen 的横版影片要出 1:1 版，都照这个做。

## 版式（1080×1080）

| 区块 | 高度 | 内容 |
|---|---|---|
| 上 banner | 196 | `remotion/src/TopBanner.tsx`，每支换三行字（见下）。底图 `remotion/public/suyenc/banner_top.webp`，裁 y 84–470 |
| 中间影片 | 608 | 16:9 原片缩到 1080×608，**完全不裁边**（裁边会切到左上题目条和左边大字，Reagan 不要） |
| 下 banner | 276 | `remotion/public/suyenc/banner_bottom.webp`（林舒苑 + 2027 战略大会 + 十二生肖/行业财富/好运指南 + ZOOM WEBINAR），**用原图**，只裁掉底部的山（y 0–530） |

- 上下 banner 都要跟影片之间留一点红色空隙，不能挤：
  - 上 banner 的字整块缩到 0.86，红色小胶囊下面留红
  - 下 banner 用原图本来的红色（2027 火焰上方）和山峰（ZOOM WEBINAR 下方）当空隙
  - **不要**另外加纯色条，**不要**模糊边、不要缩小补边
- 两张 banner 只上下压扁一点（约 5% / 3.5%），宽度永远 1080 满版

## 做法

```bash
# 已经是成片（声音调好了）
python3 pipeline/square_banner.py 横版.mp4 输出-1比1.mp4 "金色胶囊" "金色大字" "红色胶囊"
# Remotion 刚渲出来的原始片：加 --master 顺便调音量（loudnorm -15 LUFS + 限幅）
python3 pipeline/square_banner.py raw.mp4 输出-1比1.mp4 "…" "…" "…" --master
```

- 先出一张 banner 图（`npx remotion still src/index.ts TopBanner x.png --props='{"pill":…,"main":…,"sub":…}'`）给 Reagan 看字，点头再渲染
- 输出长度要跟原片一样；渲染完截一格看，确认三块都对、字没切到
- 只出单张 banner 图：上 banner 裁 `crop=2000:386:0:84`，下 banner 裁 `crop=2000:530:0:0`
